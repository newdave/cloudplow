# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and focus on the problem rather than the person.
Harassment, insults and personal attacks are not tolerated in issues, pull requests or any other project space.

## Reporting

Report unacceptable behaviour privately to the maintainer through
[GitHub's private reporting](https://github.com/newdave/cloudplow/security/advisories/new) (choose any category and
say it is a conduct report), or by contacting the maintainer through their [GitHub profile](https://github.com/newdave).
All reports are reviewed and kept confidential.

The maintainer may remove, edit or reject comments, commits and other contributions that break this code of conduct,
and may temporarily or permanently ban contributors who do so, as described in the Contributor Covenant's
enforcement guidelines.
